# ShulePlus — Module by Module

Each item below explains what that module is for, in plain language for training and videos.

1. **Authentication (IAM)** — This module is for signing in to ShulePlus once and managing the whole platform: schools (organizations), users, roles, which products each school may use, and Super Admin tools such as module catalog, user access, and national curriculum upload. Every other module depends on it for login and licensing.

2. **Student Management** — This module is for keeping the official student register and class setup: add and update students, manage classes, assign class teachers and monitors, promote students to the next year, and report on missing profile information. Other modules read student and class data from here.

3. **Academic** — This module is for teaching, learning, and examinations: subjects and courses, assessments and marks, exam sessions, seating, invigilation, report cards, grading, competency (CBC) tracking, and academic analytics for school leadership.

4. **Timetable** — This module is for building the school weekly schedule: teacher assignments, periods, automatic or manual timetable editing, conflict resolution, and exports for classes and teachers.

5. **TichaPortal (Teacher Portal)** — This module is for teachers’ daily work in one place: marks, grade book, assessments, student performance, attendance, parent messages, reports, AI insights, intervention plans, and lesson plans from national curriculum content.

6. **Teacher Portal (legacy)** — This module is for an older teacher app still used in some schools, mainly dashboard and salary advance requests; new teacher features are delivered through TichaPortal.

7. **Digital Attendance (RFID)** — This module is for recording school entry and exit with smart cards and RFID devices, applying lateness and permission rules, notifying parents, live presence monitoring, and attendance reports.

8. **RFID Device Module** — This module is for monitoring and managing RFID readers on the network: online status, configuration, remote commands, card events, unknown cards, logs, and alerts.

9. **Gate and card reader firmware** — This is not a web module; it is software on physical gate devices that reads RFID cards, stores taps when offline, and sends them to Digital Attendance when internet is available.

10. **Smart Transport** — This module is for school buses: RFID boarding and exit, live trips, GPS, parent alerts, fleet, transport fees, fuel, and maintenance.

11. **Student Discipline** — This module is for discipline cases, behavior categories, permission to leave school, gate discipline, positive behavior records, and related reports.

12. **Parent MIS** — This module is for parents and guardians to follow their child online: marks, attendance, timetable, homework, fees, messages, events, health and discipline summaries, and documents.

13. **School Fees (Fees Collection)** — This module is for collecting school money from students: fee structures, billing, payments and installments, balances, scholarships, receipts, reminders, finance dashboards, and financial reports for the bursar.

14. **School Budget** — This module is for planning how the school will spend and earn money: create budgets, allocate expenses, track usage against the plan, and manage approvals when limits are exceeded.

15. **HR** — This module is for human resources: employee records, registration, contracts, leave, departments, organization chart, staff documents, and qualifications.

16. **Payroll** — This module is for paying staff correctly under Rwanda rules: salary setup, monthly payroll runs, PAYE and RSSB, payslips, bank files, termination benefits, and staff viewing their own payslips.

17. **KaziAvance** — This module is for staff to request salary advances: check eligibility, submit requests, track approval and repayment, and upload supporting documents.

18. **Babyeyi Wizard (Circular Babyeyi)** — This module is for creating and managing school circulars (Babyeyi): write circulars in a guided flow, send them through approval (director, accountant, district, NESA as configured), publish to parents, verify with QR codes, and view analytics on downloads and reach.

19. **NESA Dashboard** — This module is for national education authority staff to oversee schools, circulars, fee policies, territories (provinces, districts, sectors), and academic calendars at national level.

20. **Sector MIS (SEI)** — This module is for Sector Education Inspectors to monitor attendance and compliance across all schools in a sector, with analytics, follow-up cases, device health, and visit planning.

21. **District MIS (DEO)** — This module is for District Education Officers to see district-wide attendance and school performance, including sectors, with the same intelligence tools as Sector MIS at district scale.

22. **School Mini-Website** — This module is for publishing a simple public website for the school and managing admission applicants and inquiry forms.

23. **Library** — This module is for running the school library: catalog books and resources, lend and return, fines and reservations, members, digital resources, and library reports.

24. **Curriculum Intelligence** — This module is for uploading and publishing official teacher guide books and letting teachers generate lesson plans in TichaPortal from approved national curriculum content.

25. **Assets Portal** — This module is for fixed school assets (buildings, equipment, vehicles): register assets, depreciation, assignments, maintenance, and QR lookup.

26. **Inventory MIS** — This module is for consumable stock in stores: products, receiving and issuing stock, transfers, counts, disposals, and inventory reports (not fixed assets).

27. **Procurement MIS** — This module is for buying for the school: purchase requests, orders, goods received, suppliers, contracts, budgets, and procurement analytics.

28. **Action Plan MIS** — This module is for strategic action plans: objectives, activities, evidence, KPIs, calendars, and budget linked to plan activities.

29. **Task MIS** — This module is for internal task and project work: tasks, kanban boards, workflows, deadlines, time tracking, and team reports.

30. **ShuleKit MIS** — This module is for platform-defined school material kits that parents or schools order (standard or custom bundles) with order tracking from request to delivery.

31. **School Uniform MIS** — This module is for selling and managing school uniforms: products, packages, stock, student assignment, sales, and optional fabric and tailoring production.

32. **Cafeteria** — This module is for the in-school feeding program: menus, recipes, meal production, beneficiaries, kitchen staff, hygiene, nutrition, and feeding reports.

33. **School Canteen** — This module is for commercial canteen operations: point of sale for operators, menus and inventory, orders and deliveries, suppliers and drivers, and platform administration of canteens on the network.

34. **Print Card MIS** — This module is for designing and exporting student and staff smart ID cards in bulk for printing, using school student data.

35. **ShuleChat (Internal Chat)** — This module is for secure messaging between teachers, parents, and staff: direct messages, groups, and announcements inside ShulePlus.

36. **School Representative Portal** — This module is for officials who supervise several schools at once: one dashboard, assigned schools, and follow-ups across those organizations.

37. **Sample Module** — This module is for developers and training only, to show how a new ShulePlus product connects to login and school data; schools do not use it in production.

38. **Notification Service** — This is a shared service (not opened like a school app) that sends email, SMS, push, and in-app notifications on behalf of IAM and other modules.

---

*Numbering follows a logical training order; your videos may reorder items (for example Fees Collection and Circular Babyeyi earlier) to match your audience.*
