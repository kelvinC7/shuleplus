What Each Module Does

BabyeyiWizard

  • School creates fee circular (Babyeyi document)
  • Defines payment line items & amounts
  • Captures school bank accounts (display on PDF)
  • NESA fee limit validation
  • Does NOT process payments

SchoolFeesPortal

  • Fee structures & student bills
  • Payment recording & receipts
  • Balance updates & notifications
  • Staff fee collection (authenticated)
  • Core payment engine

WebpageBabyeyi

  • Public school directory (babyeyi.rw)
  • Parent-facing Pay Fees wizard
  • BFF proxy to backend services
  • Get Babyeyi · Request Loan flows

Authentication + ParentMIS

  • ParentMIS: transaction history & webhooks
  • Service-to-service keys

Parent Payment Flow — 7 Steps

  1. Find school Parent selects school on babyeyi.rw
  2. Student lookup Enter ShuleCode / SDMS code → StudentManagement API
  3. Load fees SchoolFeesPortal fee structure OR Babyeyi circular fallback
  4. Choose amount Full balance, partial, or custom amount
  5. Select method Mobile Money (MTN/Airtel) · Card · Bank transfer
  6. Initiate payment POST /fees/payments/initiate → status PENDING
  7. Confirm & receipt Poll status → COMPLETED → bill updated → receipt + notify parents

What Happens on the Backend

On Initiate

  • Validate student, amount, method
  • Resolve or create student bill
  • Create payment record (PENDING)
  • Store masked details (card last4, bank ****last4)
  • Return payment reference

On Complete

  • Update bill paid amount & balance
  • Generate receipt with QR code
  • Notify ParentMIS webhook
  • Send SMS / email / push to parents
