# SVG Shapes — Academic module icon library

Odoo-style illustration SVGs for ShulePlus Academic (and reusable across modules).

**Colors:** Amber `#FCB038`, Navy `#000435`, White, Teal accent `#1FA8A0`  
**Size:** `viewBox="0 0 64 64"` — use at 48–64px inside 80×80 tiles
